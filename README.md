# 快捷方式图标修改器

> 杂货铺编号：#002

一个 Windows 快捷方式图标修改工具。

支持将常见图片转换为 ICO，并修改 `.lnk` 快捷方式的图标和名称。

## 主要功能

- PNG、JPG、BMP、WebP 等图片转 ICO
- 修改 Windows 快捷方式图标
- 修改快捷方式名称
- 支持圆形、圆角、椭圆、菱形、多边形等图标裁剪
- 可单独导出 ICO
